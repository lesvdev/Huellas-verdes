# Carpeta de Fotografías del Álbum Huellas Verdes

Guarda aquí las imágenes de las especies botánicas del proyecto:
- Formatos recomendados: `.jpg`, `.jpeg`, `.png`, `.webp`
- Ruta a usar en el formulario o en la base de datos: `/fotos/nombre_de_la_foto.jpg`

Ejemplo:
Si guardas un archivo llamado `cedro_amargo.jpg` en esta carpeta, en la ficha de la especie simplemente colocas:
`/fotos/cedro_amargo.jpg`

Todas las fotos alojadas aquí viajan directamente con el proyecto y se despliegan automáticamente en Vercel.
